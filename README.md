### 📦 Open Source Projects

#### 🌪️ Tempestroid

A bridge between Python and Kotlin for Android.

Tempestroid runs a native Python thread inside Android applications, allowing developers to directly use Python ecosystem libraries such as:

- NumPy
- Pydantic
- ONNX Runtime
- OpenCV
- Rust-based libraries
- C/C++ extensions

Its goal is to bring the power of the Python ecosystem to Android development, enabling AI, Computer Vision and data-processing applications without rewriting everything in Kotlin.

#### ⚡ Tempest FastAPI SDK

A toolkit designed to accelerate FastAPI application development by providing reusable components for authentication, databases, caching, notifications and asynchronous processing.

#### 👁️ ORT Vision SDK

A Computer Vision SDK focused on optimized inference using ONNX Runtime, simplifying AI model integration into production applications.

### 📦 Projetos Open Source

#### 🌪️ Tempestroid

Bridge entre Python e Kotlin para Android.

O Tempestroid executa uma thread Python nativa dentro da aplicação Android, permitindo utilizar diretamente bibliotecas do ecossistema Python como:

- NumPy
- Pydantic
- ONNX Runtime
- OpenCV
- Bibliotecas escritas em Rust
- Bibliotecas escritas em C/C++

Seu objetivo é aproximar o ecossistema Android do ecossistema Python, facilitando o desenvolvimento de aplicações móveis com IA, Visão Computacional e processamento de dados.

#### ⚡ Tempest FastAPI SDK

SDK para acelerar o desenvolvimento de aplicações modernas utilizando FastAPI, oferecendo componentes reutilizáveis para autenticação, banco de dados, cache, notificações e processamento assíncrono.

#### 👁️ ORT Vision SDK

SDK voltado para Visão Computacional e inferência otimizada utilizando ONNX Runtime, simplificando a integração de modelos de IA em aplicações reais.
